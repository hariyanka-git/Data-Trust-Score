⚙️ Core Algorithms & Code

The Data Trust Engine leverages statistical and heuristic methodologies to evaluate dataset health. Below are the primary algorithms implemented in the backend:

1. Interquartile Range (IQR) Outlier Detection

Used in the Accuracy metric to statistically identify values falling outside the expected data distribution.

Q1, Q3 = series.quantile(0.25), series.quantile(0.75)
IQR = Q3 - Q1
outliers = series[(series < Q1 - 1.5 * IQR) | (series > Q3 + 1.5 * IQR)]

2. Shannon Entropy & Imbalance Ratio

Used in the Bias metric to calculate representation evenness and dominance of categorical classes.

vc = df[col].value_counts(normalize=True)
imbalance_ratio = vc.iloc[0] / vc.iloc[-1]
entropy = -np.sum(vc * np.log2(vc + 1e-9))
max_entropy = np.log2(len(vc))
evenness = entropy / max_entropy

3. Statistical Skewness

Used in the Bias metric to detect heavily skewed numerical distributions (threshold > 2.0).

skewness = abs(series.skew())
if skewness > 2.0:
    penalties += min(skewness * 2, 10)

4. NLP & Lexical Heuristics

Used in the Consistency metric to parse text data and detect formatting/whitespace discrepancies alongside mixed alphanumeric characters using baseline String/NLP functions.

has_num = sample.apply(lambda x: str(x).replace(".", "").isdigit()).any()
if (sample != sample.str.strip()).any():
    ws_cols.append(col)

📊 Scoring Dimensions

Dimension Weight What It Checks
Completeness 25% Missing values per column
Consistency 20% Duplicates, mixed types, whitespace
Accuracy 20% IQR outlier detection, infinite values
Bias 20% Class imbalance, skewness, representation
Reliability 15% Dataset size, constant columns, ID leakage

🌐 Platform APIs

Endpoint Method Description
/api/evaluate POST Primary trust score engine. Accepts any CSV file or sample dataset name and returns unified JSON health matrices.
/api/compare POST Multi-dataset processor used to rank multiple uploaded CSV files simultaneously.
/api/sample/<type> GET Dynamic endpoint to fetch synthetic "clean", "messy", or "mixed" mock data.
/api/export/<fmt> POST Downloads the current analysis state as either a JSON tree or flattened CSV report.
/api/health GET Live readiness probe.

🛠️ App Stack & Dependencies

This platform was built from scratch without massive heavy web frameworks — ensuring a lightweight, extremely responsive application architecture.

1. Web Backend (Flask App)
Python Flask application routing parallel evaluations globally.
2. Engine App (Pandas & Numpy)
Numpy and Pandas power the heavy lifting of statistical aggregation arrays.
3. Analytics (Matplotlib)
Headless Matplotlib directly streaming Base64 generated visualization frames.
4. User Interface (Vanilla JS App)
Hand-written CSS UI grids and pure Javascript ES6 dynamically rendering async queries.
